



##  About SaveIQ AI

SaveIQ AI is an AI-powered savings goal tracker that helps users create financial goals, track their savings, calculate required contributions, and monitor their progress.

The application makes saving easier by providing personalized saving plans, progress analytics, and AI-powered insights.

## 🌐 Live Demo

View the deployed application:

https://saveiq-ai-zeta.vercel.app


## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS, shadcn/ui
- **Database:** Supabase PostgreSQL
- **Authentication:** Supabase Auth
- **Charts:** Recharts
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **AI:** Gemini API
- **Deployment:** Vercel

## ▶️ Run Locally

### Prerequisites

Node.js

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/saveiq-ai.git
cd saveiq-ai
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file and add your Supabase and Gemini API credentials:


### 4. Run the application

```bash

```
