# 💰 SaveIQ AI – Saving Goals Tracker

![SaveIQ AI Banner](https://via.placeholder.com/1200x300?text=SaveIQ+AI)

## 🚀 About SaveIQ AI

SaveIQ AI is an AI-powered savings goal tracker that helps users create financial goals, track their savings, calculate required contributions, and monitor their progress.

The application makes saving easier by providing personalized saving plans, progress analytics, and AI-powered insights.

## 🌐 Live Demo

View the deployed application:

https://saveiq-ai-zeta.vercel.app

## ✨ Features

- Create and manage multiple saving goals
- Set target amount and deadline
- Track savings contributions
- Calculate required daily, weekly, and monthly savings
- Monitor goal progress
- Interactive savings analytics
- AI-powered saving insights
- What-If savings simulator
- Milestones and achievements
- Savings history
- Responsive design for mobile and desktop
- Secure authentication using Supabase

## 🛠️ Tech Stack

- **Frontend:** Next.js, React, TypeScript
- **Styling:** Tailwind CSS, shadcn/ui
- **Database:** Supabase PostgreSQL
- **Authentication:** Supabase Auth
- **Charts:** Recharts
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **AI:** Gemini API
- **Deployment:** Vercel

## ▶️ Run Locally

### Prerequisites

Node.js

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/saveiq-ai.git
cd saveiq-ai
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file and add your Supabase and Gemini API credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
GEMINI_API_KEY=your_gemini_api_key
```

### 4. Run the application

```bash
npm run dev
```

Open the application at:

http://localhost:3000
